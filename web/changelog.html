v0.1.4 — 쉽게 보기 · 숫자마다 근거 · 패치 노트 대조 · 맥 실행 오류 수정

🐛 고친 것

  • 맥에서 "손상되었기 때문에 열 수 없습니다"가 뜨던 문제. 한글 실행 파일 이름 때문에 서명이 도중에 끊긴 채로 묶였어요. 이제 서명을 끝까지 하고 검사한 뒤에만 내보내요.
  • 이유 문장의 큰 퍼센트("회복·보호막이 263% 늘어요")를 실제 숫자로 바꿨어요 → "회복·보호막이 늘어요 (402 → 1,538)"
  • 계산이 설명과 안 맞던 증강 2개: 신난다! 공격 속도 3% → 2.25% (15% × 가동률 15%), 급속 성장 최대 체력 20% 부분 반영

✨ 새로 생긴 것

  • 쉽게 보기 (기본): 처음 보는 사람도 헷갈리지 않게 3단계 안내 + 추천 평가 · 이유 · 살 아이템만. 능력치 표·점수·가중치는 맨 위 자세히 보기에서.
  • 📐 근거 보기: 증강·아이템마다 숫자가 어디서 왔는지 — 📊 게임 데이터 / 📖 설명 수치 / 🧮 계산 / ⚠️ 가정(+이유) / ⏱️ 발동 빈도. 근거 없는 가정값은 데이터를 만들 때 경고가 나요.
  • 계산 가정값 표: 데이터 출처 페이지에 공통 가정 12개와 이유.
  • 패치 노트 대조: 패치 노트 줄마다 게임 데이터·위키와 맞춰 봐요 (✅ 반영 확인 · 📄 패치 노트 값으로 임시 계산 · ⚠️ 이전 값 · ❔ 못 찾음). 챔피언 모드 보정·재사용 대기시간·증강 수치는 게임 데이터가 늦으면 확실한 줄만 패치 노트 값으로 계산해요.
  • 기록 파일 위치 안내 (사용 설명서): 윈도우 %APPDATA%\AramAugment\logs

🎯 더 정확해진 것

  • 기준 상대를 정한 값(체력 3000·방어력 80·마법 저항력 60)에서 전 챔피언 173명의 18레벨 추천 빌드 중앙값(체력 2470·방어력 113·마법 저항력 63)으로 바꿨어요.

v0.1.3 — 새 증강 자동 반영 · 출처 표시 · 매일 자동 갱신

✨ 새로 생긴 것

  • ✨ 새 증강 표시: 이번 패치에 처음 나온 증강에 표시가 붙어요.
  • 🤖 새 증강 자동 추정: 아직 사람이 규칙을 안 만든 증강도, 설명의 조건 없는 능력치 문장("치명타 확률이 25% 증가합니다")을 읽어서 바로 숫자로 평가해요. 직접 만든 규칙 12개와 대조해 12개 모두 일치했어요.
  • 확인 필요 자동 알림: 매일 갱신 때 새 증강, 설명이 바뀐 증강, 패치 노트 숫자와 게임 데이터가 다른 것, 규칙이 깨진 것을 모아 GitHub 이슈로 올려요.
  • 상대 고르기: 능력치 패널의 '상대'에서 챔피언을 고르면 그 챔피언의 18레벨 추천 빌드 능력치로 피해를 계산해요. 예) 상대 말파이트(체력 5,457·방어력 313)
  • 🆕 이번 패치 표시: 라이엇 공식 패치 노트의 아수라장 변경을 가져와서, 바뀐 증강·챔피언에 표시해요. 예) 지옥불 난사 발동 "재사용 대기시간 15초 ⇒ 5초"
  • 🔗 출처 링크: 증강·챔피언·아이템마다 정보를 가져온 곳(게임 데이터, 위키, 패치 노트)으로 가는 링크가 붙어요.
  • 통계 보기 (외부): 증강마다 승률 통계 사이트로 가는 링크. 통계는 가져오지 않고 링크만 걸어요.
  • 데이터 출처 페이지: 맨 위 "데이터 출처"에서 가져온 곳 16곳의 링크·라이선스·받은 시각과 이번 패치 아수라장 변경 전체를 볼 수 있어요.
  • 매일 자동 갱신: 웹 버전은 매일 새벽 3시에 새 데이터를 받아요 (바뀐 게 있을 때만). 프로그램은 "데이터 갱신" 버튼으로 받아요.

🎯 더 정확해진 것

  • 상대 체력 % 피해가 스킬 피해에 들어가요 (25명). 예) 문도 박사 Q 현재 체력 20~30%, 제이스 E 최대 체력 8~22%, 가렌 R 잃은 체력 25~35%. 체력 소모(로크 W 등)는 빼요.
  • 중첩당 수치 표시: "?"였던 자리 중 중첩 비례 값을 "중첩당 20"처럼 보여 줘요. 스킬 못 채운 자리 77 → 71곳, 증강 17 → 15개.
  • 소환 특징: 9명 → 14명 (엘리스·아지르·일라오이·나피리·마오카이 추가) → 소환술사 같은 증강 판정에 반영

🐛 고친 것

  • 능력치 패널의 체크 상자가 넓게 늘어나 보이던 문제

⚠️ 수집 원칙

  • 라이선스가 허용하는 곳(위키 CC BY-SA 등)과 공개된 공식 자료만, 하루 1번, 출처를 남겨서 가져와요.
  • 승률 통계 사이트는 이용약관상 자동 수집하지 않아요.

v0.1.2 — 정확도 대폭 개선

한 줄 요약: "정확한 지표가 곧 재미" — 게임 파일과 위키에서 칼바람 증강 모드 전용 수치를 찾아 넣고, 숫자로 평가되는 증강을 77개 → 137개로 늘렸어요.

✨ 새로 생긴 것

  • 기동성 · 제어력 지표: 능력치 패널에 두 칸이 생겼어요.
    • 기동성 = 평균 이동 속도 (조건부 이동 속도는 켜져 있는 시간 비율로)
    • 제어력 = 콤보 한 번에 거는 CC 시간 (기절·속박은 그대로, 둔화는 30%만)
  • 📐 계산 기준: 숫자가 아닌 효과를 어떻게 계산했는지 증강마다 적어 둬요.
  • 아이템 같은 계열 안내: 주문 검·히드라·치명 계열처럼 하나만 효과가 있는 아이템은 같이 추천하지 않고, 직접 고를 때도 알려 줘요.

🎯 더 정확해진 것

  • 칼바람 증강 모드 전용 스킬 수치를 씁니다. 예) 바드 미프 주문력 계수 50% → 67%, 가렌 패시브 회복 → 2~12% (패치 26.20 노트와 일치)
  • 증강 모드 전용 재사용 대기시간: 가렌 W 22 → 18초, 크산테 W 14 → 10초, 스카너 E, 쓰레쉬 W
  • 증강 모드 전용 챔피언 보정 59명: 일반 칼바람 보정 위에 증강 모드 보정을 덮어써요. 예) 아크샨 가하는 피해 +5% → 0%
  • 쿨 반환·초기화 증강을 스킬 가속으로 환산: 신비한 주먹, 대마법사, 노련한 저격수, 궁극기 대변혁 등 25개
  • 조건부 효과를 기대값으로: 윤 탈 야생화살(치명타 영구 중첩), 쇼진의 창, 나보리 명멸검, 생명선 아이템 등
  • 무적·피해 감소 → 버티는 힘, 골드·모루 → 능력치(위키 골드 효율 기준)
  • 증강 적용 스킬 목록: 승리를 위한 회전은 위키에 나온 24명만 발동해요.

🐛 고친 것

  • 레벨 구간 계산 버그: 레벨에 따라 증가량이 바뀌는 수치를 낮게 계산하던 문제. 스킬·패시브 77개의 18레벨 값이 바로잡혔어요 (다리우스 패시브, 쉔 Q, 파이크 R 등).
  • 비활성 증강: 위키에 '현재 비활성'으로 나온 신발 수집가를 추천에서 뺐어요 (모두 8개).

⚠️ 알아 두세요

  • 가정값(받는 피해 초당 600, 가동률 등)은 실제 게임과 다를 수 있어요. 이상하면 알려 주세요.
  • 위키 증강 모드 보정 표는 기준 시점이 25.17로 적혀 있어 최신 패치와 조금 다를 수 있어요.

v0.1.0 — 첫 공개

✨ 기능

  • 첫 증강 추천 → 다음 증강은 고른 증강과의 연계 순서로 추천 (🔥 강력 추천 ~ 🎲 도전, ⛔ 효과 없음, 🔄 변신)
  • 이번 선택지: 게임에 뜬 증강 3개를 넣으면 비교하고, 새로고침할 칸도 알려 줘요.
  • 다음에 살 아이템과 추천 빌드 (증강 몰빵 · 균형 · 변칙)
  • 게임 연동: 챔피언·레벨·산 아이템 자동 반영
  • 게임 화면 표시 (윈도우, 창 모드·테두리 없음): 증강 카드 밑에 평가, 오른쪽 위에 다음 구매
  • 상점 추천 등록: 챔피언이 정해지면 게임 상점 추천 칸에 우리 빌드를 넣어요.
  • 작게 보기, 항상 위, 데이터 갱신
